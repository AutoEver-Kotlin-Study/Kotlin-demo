# 보완 사항


## lock

- AS-IS) db lock + in memory lock 사용중
- TO-BE) redis의 zset 등을 이용하여 분산 시스템에서도 동작하다록 설계 필요. 특히 lock이 걸렸으면 내 앞에 몇 사람이 더 있는 지 등 표시해줘야 될 것 같음.


## 성능 및 동기화
- AS-IS) db에서 조회. 유저 좌표 값은 인메모리에 저장
  - 현재 싱글 서버에서는 괜찮음
- TO-BE) redis에 유저 좌표 값 저장 필요.

## 기타

- 테스트 편하기 위해 groupID를 컨트롤러에서 입력받도록 했음
  - userID처럼 uuid 등 이용해서 자동 생성할 필요 있음.
