# 아키텍쳐


## 헥사고날 아키텍처

참고: https://github.com/thombergs/buckpal


- `port.in`: 외부에서 들어오는 요청(Controller 등).
  - `usecase`로 정의하고, 이는 서비스
  - `controller`에서 in port를 타고 서비스(비즈니스 로직) 레이어으로 접근
- `port.out`: 외부로 나가는 요청(DB 등)
- `adapter`: `port`를 구현하는 구현체

### 헥사고날을 이용한 이유

- 추후 scale out 위해 적용
  - 특히 lock의 경우 redis를 이용하는 등의 방향이 적합함
  - db 변경
  - 알림을 줄 경우, 알림 관련 회사를 이용할 수도 있고 aws 등 클라우드 내장된 기능을 이용할 수도 있음. 또한 카카오톡/이메일/fcm 등 확장될 여지가 있음.
